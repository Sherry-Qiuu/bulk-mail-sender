# 邮件群发工具 · Bulk Mail Sender

一个开箱即用的 **Windows 本地邮件群发工具**：带图形界面，无需命令行，支持从 Excel/CSV 名单读取收件人，并通过 `{列名}` 占位符实现**批量个性化邮件**（如「亲爱的 {姓名} 同学」）。

> 纯本地运行，收件人名单和授权码不上传任何服务器（勾选「记住授权码」时仅明文保存在本机 `config.json`）。

## ✨ 功能特性

- 🖥️ **图形界面**：双击即用，四步流程（设置邮箱 → 读取名单 → 写邮件 → 发送）
- 📊 **名单来源灵活**：支持 `.xlsx` / `.csv`，第一行表头，除「邮箱」外可随意增删列
- 🏷️ **个性化占位符**：主题和正文均可用 `{列名}`，按名单逐行替换；未识别的占位符原样保留
- 📧 **服务商预设**：Gmail / Outlook(Microsoft 365) / QQ 邮箱 / 163 邮箱 / 自定义 SMTP
- 🎨 **HTML 正文**：支持加粗、颜色、链接等富文本格式
- 🧪 **测试邮件**：正式群发前先发给自己确认效果
- ⏱️ **发送间隔**：默认 3 秒/封，降低被判定为垃圾邮件的风险
- 🔁 **断线重连**：SMTP 连接中断自动重连并重试当前收件人
- 📝 **实时日志**：逐封显示成功/失败，失败地址可修正名单后补发
- ⏹️ **随时停止**：发送过程中可一键中止

## 🚀 快速开始

### 1. 环境要求

- Windows 系统
- [Python 3.8+](https://www.python.org/downloads/)（安装时勾选 **Add python.exe to PATH**）

### 2. 安装依赖

```bash
pip install openpyxl
```

> 不装 openpyxl 也能运行，但只能用 CSV 名单（推荐安装以支持 Excel）。

### 3. 获取邮箱授权码（不是登录密码！）

| 邮箱 | 步骤 |
|------|------|
| **Gmail** | 开启两步验证 → [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords) 生成 16 位应用专用密码 |
| **Outlook / M365** | 开启两步验证 → account.microsoft.com → 安全 → 高级安全选项 → 创建应用密码 |
| **QQ 邮箱** | 设置 → 账户 → 开启 SMTP 服务 → 获取授权码 |
| **163 邮箱** | 设置 → POP3/SMTP/IMAP → 开启服务 → 获取授权码（有每日限量） |

### 4. 运行

双击 **`启动邮件群发工具.bat`**，或：

```bash
python mail_sender.py
```

## 📖 使用流程

1. **① 发件邮箱设置**：选择服务商预设，填入邮箱和授权码
2. **② 收件人名单**：点「生成模板」得到 Excel 模板 → 填好名单 → 点「读取名单」
   - 表头必须含「邮箱」列；其余列（如 姓名/班级）均可作为占位符
3. **③ 邮件内容**：写主题和正文，用 `{列名}` 插入个性化字段
   ```
   主题：关于{活动名}的通知
   正文：亲爱的 {姓名} 同学：
         你所在的 {班级} ……
   ```
4. **④ 发送**：先「发送测试邮件」给自己确认，再「开始群发」

详细说明见 [docs/使用说明.txt](docs/使用说明.txt)。

## ⚠️ 注意事项

- 请遵守所在地区法律法规及邮箱服务商的反垃圾邮件政策，**勿用于发送垃圾邮件**
- Gmail / Outlook 必须使用「应用专用密码」，普通登录密码无法通过 SMTP 认证
- 群发间隔建议 ≥ 3 秒；163 邮箱有每日发送数量限制
- 公用电脑上请勿勾选「记住授权码」
