邮件群发工具 · 使用说明
========================

一、怎么打开
  双击「启动邮件群发工具.bat」即可。

二、先拿到邮箱授权码（不是登录密码！）
  · Gmail：账号需先开启两步验证 → 访问 myaccount.google.com/apppasswords
    生成一个「应用专用密码」（16位），填到工具的授权码框里。
  · Outlook / Microsoft 365：账号开启两步验证后，在
    account.microsoft.com → 安全 → 高级安全选项 里创建应用密码。
  · QQ / 163：设置 → 账户 → 开启 SMTP 服务，获得授权码。
  注意：163 邮箱群发有每日数量限制（约几十封），量大建议用 Gmail 或企业邮箱。

三、准备收件人名单
  1. 点「生成模板」得到 名单模板.xlsx；
  2. 第一行是表头（必须保留「邮箱」列），下面每行一个收件人；
  3. 可以随意增删列，比如加「班级」「学院」，列名就能在邮件里用。

四、写邮件内容
  主题和正文里都可以用 {列名} 占位符，发送时自动按每行替换：
    主题：关于{活动名}的通知
    正文：亲爱的 {姓名} 同学：
          你所在的 {班级} ……
  勾选「HTML 格式」后正文可以写 HTML 标签（<b>加粗</b>、<a href>链接等）。

五、发送建议
  · 先点「发送测试邮件」发给自己，确认内容和格式没问题；
  · 每封间隔建议 3 秒以上，发太快容易被邮箱判为垃圾邮件封号；
  · 发送日志里能看到每个地址的成功/失败，失败的可以修好名单后再发；
  · 勾选「记住授权码」会明文存在本机 config.json 里，公用电脑别勾。

六、常见失败原因
  · 授权码错误 / 未开启 SMTP → 重新生成授权码；
  · Gmail 提示 "Less secure app" → 必须用应用专用密码，不能用登录密码；
  · 连接超时 → 检查端口（SSL 用 465，STARTTLS 用 587）和校园网/防火墙。
